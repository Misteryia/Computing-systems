# Практическое занятие: ассемблер RISC-V в симуляторе RARS

Вариант: номер студента в списке группы **n = 4**, номер группы **y = 26**.

## Программы

| Файл | Задача |
|---|---|
| [`task_a.asm`](task_a.asm) | (а) Ввод целого x → вывод `1`, если x равен номеру студента (4), иначе `0`. |
| [`task_b.asm`](task_b.asm) | (б) Ввод целого x → все значения от min(x, 26) до max(x, 26) с шагом 4, через пробел. |
| [`task_c.asm`](task_c.asm) | (в) Заполнение массива из 16 + 4 = 20 целых чисел со стандартного ввода. Чтение прекращается после 20 значений или при вводе 0. |
